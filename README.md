## Technology Stack

This personal website is built using a modern, production-ready web stack.

### Core Framework
- **Next.js** – React-based framework providing routing, layouts, SEO, and performance optimizations

### UI & Language
- **React** – Component-based UI library
- **TypeScript** – Primary programming language for type safety and maintainability
- **JavaScript (ESNext)** – Underlying runtime language
- **HTML (JSX/TSX)** – Semantic markup via React components

### Styling
- **Tailwind CSS** – Utility-first CSS framework for consistent, responsive styling
- **CSS** – Base styles and global overrides

### Tooling & Runtime
- **Node.js** – Development and build runtime
- **npm** – Package management and task runner
- **ESLint** – Static code analysis and linting
- **Prettier** – Code formatting

This stack was chosen for scalability, maintainability, performance, and long-term growth beyond a simple portfolio site.
